# STS司机账号与操作

管理员可通过左上角“STS司机账号”（`/auth/sts-driver-account`）设置一个专用账号，默认账号名为 `STS01`。登录后进入 `/sts-driver`，操作场景中的 `STS_01`。更新代码后须重启Kit，使新角色鉴权和独立画面服务生效；同一浏览器配置内的普通标签页共享Cookie，不同角色同时登录需使用不同浏览器或独立浏览器配置。

| 按键 | 功能 |
|---|---|
| W / S | 岸桥大车正向 / 反向 |
| A / D | 岸桥小车移动 |
| Q / E | 吊具上升 / 下降 |
| 1 / 2 | 吊具20 / 40尺切换 |
| 空格 | 停止STS驾驶轴 |
| F | 当前视角从140°每次收窄10°至10°后循环 |
| V | 吊具下方、侧向、端向视角循环 |
| K / U | 闭锁取箱 / 开锁落箱 |

下视相机位于小车平台下方并随小车移动，保持垂直向下，画面相对原方向顺时针旋转90°；侧向和端向相机跟随吊具。采用独立USD渲染上下文和WebRTC流（信令49250、媒体48010，1280×720/20fps），与RTG和集卡设备占用、视口、操作请求分开。只操作本地可视化会话，不发送PLC指令。离开页面、失焦、视频中断或输入超时会停止该岸桥的手动轴控制。

闭锁要求四个锁点接触同一只无遮挡、尺型匹配的箱顶并对准中心；不能闭锁其他设备仍持有的箱子。开锁要求箱子四个底部承重点落在集卡或其他箱子上，集卡交接时必须停稳。落车开锁后箱子随集卡移动，并能被RTG识别；载箱期间禁止切换尺型。STS司机退出时保留悬吊箱子和闭锁状态，下次登录可继续操作，其他自动作业不能抢占。

吊具和载箱的移动按场景几何限制，遇到船图箱子、集卡车头/车身/承载面、码头地面或船舶建筑会停下并显示提示。此为可视化运动保护，使用包围盒近似，不代表完整物理仿真或全部场景碰撞；船图结构箱位是演示对象，不代表已确认的实际配载。当前未实现吊具旋转和倾斜控制。独立画面会增加显存压力，8GB显存设备同时打开多个独立司机画面时需要实测资源占用。
