# RTG司机账号与操作

管理员登录后点击左上角“RTG司机账号”（`/auth/rtg-driver-account`），可创建或修改一个RTG司机账号，建议名称 `RTG01`。密码至少10位，修改只会使该账号的旧会话失效，不影响集卡司机或管理员。密码仅保存加盐哈希。

RTG司机登录自动进入 `/rtg-driver`，只具备主RTG的模拟操作权限；不能操作集卡、管理Agent或管理员视口。admin仍使用原有RTG初始管理视角。不同角色同时登录时使用不同浏览器或独立浏览器配置；同一浏览器配置内的普通标签页共享登录Cookie。

| 按键 | 操作 |
|---|---|
| W / S | 大车正向 / 反向 |
| A / D | 小车左 / 右 |
| Q / E | 吊具上升 / 下降 |
| Z / C | 吊具左倾 / 右倾（限±5°） |
| J / L | 吊具向左 / 向右旋转微调（限±5°） |
| H | 旋转与左右倾平滑回零 |
| 1 / 2 | 连续伸缩至20尺 / 40尺 |
| K / U | 闭锁取箱 / 开锁落箱 |
| 空格 | 停止全部RTG轴，不停止集卡 |
| F | 当前视角从140°每次减10°，到40°后回到140° |
| V | 吊具下方 → 侧向 → 端向 → 吊具下方 |

默认相机固定在小车平台下方，垂直向下，跟随小车和大车，不随起升或倾斜移动。F只改变焦距，三个视角均可在40°至140°循环调整，保持各自相机位置与方向。侧向、端向视角随吊具移动，用于观察吊具与箱顶间距。

吊具下降触及箱顶、载箱下降触及集卡承载面或车头时会停止下降并显示提示；可向上升起脱离接触。接触判断使用场景几何，属于演示模式的运动限制。

控制沿用RTG工程坐标和软限位，仅修改场景会话层，不发送PLC指令。松开按键相应轴停止；输入超过350毫秒未更新、页面失焦或画面中断时停止RTG；会话退出/过期释放RTG占用，保留设备当前位置。不能接管正在运行的自动任务、PLC、仿真或手柄控制。

页面按钮与上述快捷键等效，显示实际尺型、伸缩到位、旋转角度和锁具状态。20/40尺切换要求空载且停止，伸缩期间不移动其他轴，未到位不能闭锁。空格、失焦或输入超时会停止伸缩和回零；若停在中间尺型，需要再次选择20尺或40尺完成伸缩。

闭锁使用实际四角锁脚与箱顶几何校验：四脚须落在同一只无遮挡的箱顶、锁点对齐、实际尺型匹配；不能隔空吸箱。闭锁后箱体、门和导入外观整体随吊具升降、横移及微调，禁止载箱大车移动或切换尺型。开锁前四个底部承重点须由地面、箱顶或集卡承载面支撑，禁止悬空开锁。此模式使用会话层几何和运动绑定，不启动重力或PLC物理仿真。

与集卡交接时集卡须停稳。开锁落到集卡后，箱子跟随该车运动，RTG账号退出不影响集卡载箱继续行驶；集卡自己的载箱不会被判为自身碰撞。集卡退出驾驶并归位时载箱随车归位。RTG若带箱退出，保留闭锁和当前位置，下一次RTG登录可继续操作；落稳开锁前，其他RTG自动任务不能接管设备。

RTG与01号集卡各自持有设备、相机、USD渲染上下文、编码线程和WebRTC服务。RTG信令端口49240、媒体48008；集卡保持49230/48006。两路均为1280×720、20fps，不使用管理员主画面输入通道。RTG移动只刷新集卡附近动态构件碰撞信息，不重建整个场景碰撞索引。关闭任一路驾驶视口只释放自己的资源。

HTTP接口 `/api/rtg-driver/acquire`、`input`、`release` 使用POST，`state` 使用GET。服务器同时验证RTG角色、登录会话和每页随机 `client_id`。输入只接受 `gantry`、`trolley`、`hoist`、`roll`、`yaw`、`brake`、`view`、`fov`、`seq` 及单次操作 `size_ft`、`lock`、`zero`；旧序号不覆盖新指令，单次操作不会随输入心跳重复发送。集卡账号不能调用RTG接口，RTG账号不能调用集卡接口。

更新后重启Kit以加载新的鉴权和主线程路由，然后重新登录。可用 `tests/test_rtg_driver_usd.py` 验证实际场景轴运动、私有相机、倾斜与集卡并发；`tests/rtg-driver-web.test.cjs` 验证按键；`tests/test_webrtc_auth.py`、`tests/test_truck_driver_api.py` 验证角色隔离；`tests/kit_role_viewport_smoke.py` 在最小场景验证三路独立RTX渲染与两路司机编码继续出帧。
