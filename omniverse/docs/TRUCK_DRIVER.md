# 集卡驾驶员模式

完整退出并重新启动 Kit，让登录中间件、HTTP路由、网页资源和驾驶控制器一起加载新版本；仅刷新网页不会更新已导入的Python模块。

## 账号与进入

1. 使用现有管理员账号登录，在左上角选择“驾驶员账号”，或打开 `/auth/driver-account`。
2. 创建账号（默认名称 `driver`），设置至少10位密码。也可用此页面修改已有驾驶员密码；旧驾驶会话立即失效。
3. 使用驾驶员账号登录，页面自动进入 `/driver` 并取得01号集卡驾驶权限，初始为驾驶室视角。可用另一浏览器或独立无痕会话同时登录管理员；同一浏览器配置中的标签页共享登录Cookie。

账号密码沿用PBKDF2哈希存储，不提供通用默认密码，也不更改原有管理员/观众账号。目前仅一个驾驶员账号、一辆01号集卡、一个有效驾驶会话；同一账号的第二个浏览器不能同时抢占车辆。若自动搬运仍占用车辆，页面会提示，需先正常结束并复位搬运演示，再点击“重新进入驾驶”。

驾驶员使用独立USD渲染上下文和WebRTC Core画面流（信令49230、媒体48006，1280×720/20fps），不占用现有3路观众流。沿用现有官方 `omni.kit.livestream.webrtc` 和 `omni.kit.livestream.core` 扩展；独立上下文的离屏帧转换为BGRA后经CUDA缓冲区送入WebRTC。驾驶指令走经过角色鉴权的HTTP接口，不开放WebRTC原生鼠标键盘控制通道；独立流未就绪时保持制动；获取配置失败时也禁止回退连接管理员主流。司机渲染使用异步Hydra纹理，画面回调只复制像素，独立编码线程负责CUDA上传及WebRTC推送；队列只保留最新一帧，编码或退出等待不会阻塞管理员主线程。

## 操作

| 按键 | 动作 |
|---|---|
| W / ↑ | 前进 |
| S / ↓ | 制动后退 / 倒车 |
| A、D / ←、→ | 左右转向 |
| 空格 | 刹车 |
| V | 驾驶室 / 车外跟随切换 |
| R | 停车并重置到初始位置 |

当前是演示层的单车运动模型，具有加减速、转向和车身碰撞；车辆及驾驶室几何保留在可移除的会话层。车内模式增加简化仪表台、方向盘和窗框，并移除该视角中的不透明原车身/黑色窗片遮挡；车外视角恢复原车外观。车轮按堆场、岸边及实际引桥/岸桥平台表面高度行驶。管理员新登录时恢复原RTG初始视角；集卡司机切换车内/车外视角只写入独立相机。车辆位置通过共享场景会话层同步，驾驶室外壳隐藏等外观修改只在司机场景层生效。观众继续只读观看管理员画面。

## 碰撞、落海与退出

- 启动时先准备集卡附近及当前行驶方向的较长区域，再解除初始制动。行驶中根据方向提前约两秒的位置准备有重叠的走廊区域，复用不变的物体分类、包围盒与精确几何缓存，并保留最近8个已检查区域供转弯、掉头使用。后台大区块未完成时，同步完成车身附近半径16米的精确检查（包括下一步扫掠范围）再继续行驶，不再因为区块切换而直接制动。实际障碍碰撞、失去有效驾驶输入和初始化期间的制动保留。初始扫描每帧约3毫秒，行驶预加载约10毫秒预算。准备状态显示已检查对象数；移动起重机全局登记并按需生成低处几何，渲染元数据变化不触发碰撞重建。
- 按实际车身长宽计算旋转后的矩形，移动细分到最多4厘米/半度，先检测再提交位置；撞到箱子、其他车辆、建筑、桥栏或起重机低处构件时停在碰撞前，可后退或转向脱离。
- 合并护栏/立柱/起重机网格按车辆高度范围内的网格面检测，不把整个大包围盒当作实心障碍；跨越车辆高度的小型斜撑也必须裁切，避免上方构件的投影封住RTG车道。车辆未使用真实PhysX动力学，复杂曲面采用保守碰撞范围。
- 相机绿色定位球、雷达定位示意、guide辅助几何和车辆编号不参与碰撞。四个引桥口使用分段路缘石，移除横跨入口的旧连续路缘石，保留真实侧边护栏。碰撞提示会显示“引桥护栏”“集装箱”“RTG构件”等对象类别，便于区分实际接触和误判。
- 两条岸桥地面钢轨高出码头面9厘米，允许车辆横跨；仅当指定钢轨不高于所在路面10厘米且宽度不超过20厘米时适用。岸桥轮组、支腿、高架轨道和护栏仍属于障碍物。
- 支撑范围来自堆场地面及场景中实际存在的引桥、岸桥平台。车轮离开支撑面时判定落海，立即重置到初始位置，清零车速、油门和转向。
- 输入每100毫秒发送，序号防止旧油门指令覆盖较新的停车指令。失焦、隐藏页面或超过350毫秒未收到输入会停车；退出、会话失效或10秒无有效心跳会释放车辆，恢复原停车车辆和先前视角。
- 驾驶与自动搬运互斥。驾驶员无Agent、设备控制、语音、账号管理权限；管理员在驾驶期间仍可查看、切换RTG及岸桥视角；会争用01号集卡的搬运和库存重载仍受互斥限制。服务器校验角色、会话、指令范围和同源请求，前端隐藏按钮不作为权限边界。

## 接口与代码

`/api/truck-driver/acquire`、`input`、`release` 只接受驾驶员POST；`state` 为只读GET。账户身份由服务器验证的会话传入主线程；每个页面使用随机 `client_id` 区分，防止同账号第二个标签页抢占，以及旧页面的退出请求释放新页面的车辆。客户端不能指定车辆、USD路径或其他登录身份。除页面标识外，控制请求只能包含 `throttle`、`steer`、`brake`、`view`、`reset`、`seq`。

- `webrtc_auth.py`：驾驶员账号、登录跳转、权限与注销。
- `role_viewport.py`：独立司机USD上下文、离屏RTX相机、WebRTC Core画面流和资源释放。
- `truck_driving.py`：运动、碰撞和落海重置。
- `truck_driver_runtime.py`、`truck_driver_cab.py`：USD车辆、驾驶视角、场景碰撞与资源占用。
- `web_bridge.py`：主线程路由与驾驶更新；直接提供项目网页资源，无需修改Kit安装目录。
- `smartport-driver.js`：驾驶按键、视角切换、状态提示和输入心跳。

## 角色扩展范围

| 角色 | 当前入口与画面 | 当前能力 |
|---|---|---|
| admin | 管理页，登录初始化RTG视角 | 管理、Agent及设备操作 |
| viewer | 只读观众页，观看管理视口 | 无设备控制权限 |
| driver（集卡司机） | 独立集卡车内/车外画面 | 01号集卡驾驶 |
| rtg_driver（RTG司机） | 独立下视/侧向/端向画面 | 主RTG大车、小车、起升和左右倾；见 [RTG司机操作](RTG_DRIVER.md) |
| sts_driver（STS司机） | STS_01 独立下视/侧向/端向画面 | 岸桥轴控制与尺型切换；见 [STS司机操作](STS_DRIVER.md) |

新增角色需要同时配置服务端操作权限、设备占用、私有相机/上下文和独立画面流；不能仅隐藏前端按钮。当前仍为单辆集卡，观众流最多3路，不承诺任意数量用户独立渲染。

### 连续驾驶诊断

驾驶状态包含 `collision_strategy=exact_local_with_prefetch_v2`、局部检查次数/耗时、物理几何更新次数及最近更新路径。大型三角形/四边形网格使用NumPy批量高度裁切，并与标量算法做数值一致性测试；缺少NumPy时保留标量路径。辅助定位标记更新不重建碰撞区域，真实物体移动会立即废弃旧预加载和缓存。附近RTG、岸桥的低处构件在区域预加载阶段分帧预热，避免首次靠近时集中生成碰撞几何。
