# RTG 多视角作业画面

`RTG Work Views` 面板在一个窗口里并排显示实时数字模型：

- 左侧：小车平台下方正下视，跟随大车和小车；相机安装高度不随起升改变，镜头根据吊具高度自动变焦。
- 中间：吊具侧面视角，跟随吊具，便于观察吊具与箱顶的间隙和抓放过程。
- 右侧：接近 RTG 正面、略偏左 12°，以 8° 轻微俯角看向整机中心，整机充满主要画面，同时显示上部平台、吊具和箱顶，跟随大车移动。小车和吊具移动时整体构图保持稳定。

重启 Kit 加载更新的菜单及 Agent 工具后，选择 **Window > RTG Work Views**，或对 Agent 说：

> 打开 RTG 作业三视角，同时显示正下视、侧面抓放箱和整台 RTG 的斜视全景。

对应 `control_camera_display(display="work_views", action="start")`。
`action=status/stop/refresh` 可查询、关闭或重新显示；重复启动复用面板。

面板默认与主 Viewport 停靠在同一区域，可拖动标题栏调整布局。
顶部 **Top down / Side / Overview** 三个勾选框分别控制正下视、侧视和整机全景。
默认开启前两个，关闭第三个；可以任意组合或全部关闭，剩余画面自动铺开。
关闭的画面暂停渲染；全景首次开启时才创建视口。勾选状态会记住，重新打开面板或重启后沿用。
**Other side** 切换观察侧，**Closer / Wider** 调整侧视远近。
**Top auto zoom** 默认为开启：吊具下降时增大焦距，上升时减小焦距。
以工程起升高度为准，15 米附近使用广角，10 米附近适度放大，5 米附近进一步放大。
参考焦距分别约 12.6、24、40 mm，档位之间连续插值，并以约 0.45 秒的响应时间平滑过渡。
根据实际模型距离、吊具旋转与偏移限制最大焦距，保证四个锁脚仍在画面内。
关闭开关恢复固定 110° 广角；侧视镜头不受此开关影响。
若某一侧被堆箱或 RTG 结构遮挡，可换到另一侧或缩短侧视距离。
三个画面使用同一实时场景，兼容 ZMQ PLC、TwinState 与仿真驱动，不申请设备控制权。

每个视口渲染分辨率限制为 960×720，相机跟随按最多 30 Hz 更新。
后台标签暂停附加视口渲染；关闭或切换场景会释放视口与临时相机。
多视角增加渲染工作量，实际 FPS 取决于 GPU 和场景；不修改全局 RTX 质量设置。
相机写入临时会话子层，关闭后移除；不写入场景源文件。

也可在 Kit Script Editor 中运行：

```python
from rtg_work_views import start_rtg_work_views
start_rtg_work_views()
```
