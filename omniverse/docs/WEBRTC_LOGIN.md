# WebRTC 网页账号

首次启动后，在服务器本机打开 `http://127.0.0.1:8011/`，初始化管理员与观众两个账号。初始化只允许本机回环地址访问；不提供默认密码。密码至少10位，保存为随机盐PBKDF2哈希，数据位于被Git忽略的 `.cache/webrtc-auth/accounts.json`。

管理员登录进入主流，能使用Agent及视角控制；观众登录后强制进入 `?spectator=1`，HTTP接口拒绝Agent、视角及其他控制请求，只返回观众流配置。页面左上角提供退出登录。会话8小时过期，重启服务需重新登录；每IP一分钟最多8次登录尝试。

本模块保护8011网页与HTTP接口，不负责NVIDIA原生49100/49200信令端口认证。现有原生端口直连不经过网页会话校验；如需将账号权限作为完整的网络访问边界，应另行限制这些端口的网络访问并配置认证信令代理。当前HTTP未提供传输加密，公网部署需HTTPS。

验证包括：远程不能初始化、重复初始化拒绝、密码不以明文存储、未登录拦截、观众控制接口403、管理员允许访问、会话退出/过期、请求来源检查、登录限速。
