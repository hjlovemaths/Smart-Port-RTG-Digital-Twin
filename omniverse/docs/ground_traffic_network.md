# 地面交通标线方案

场景图层：`ground_traffic_network.usda`，由
`build_ground_traffic_network.py` 生成，已接入 `smart_port.usda`。

岸桥轨道之间布置四条 3.5 米车道，2+2 双向；同向车道之间是白色
虚线，对向之间是双黄线。旧岸边两条车道及陆侧旧车道标线采用更强
图层隐藏，可恢复。轨道保留。

四条引桥与 1C—4C 横路双向连接岸桥、临水主路、堆场作业通道及
外侧主路。中心线在交叉口断开，允许车辆转入作业区。外侧 15 米主路
供停车区出车和外部集卡交通使用；停车位直接接入该主路。

堆场内所有集卡作业通道统一从大贝位驶向小贝位（场景 Y 负方向），
从各区大贝位端进入、小贝位端驶出，经横路和双向主路返回。
狭窄的 RTG 间隙及灯杆所在条带不作为新增双向车道。

外部进出口按参考截图解释为 4C 前方横路的外侧延长段，坐标
X=125.5..150，Y=386.55；空车和载箱车共用入口、出口两个方向。

路线：停车位 → 外侧主路 → 任意横路 → 堆场作业通道或引桥 → 岸桥；
堆场 → 横路 → 引桥 → 岸桥；外部门口 → 外侧主路 → 横路 → 堆场。
岸桥与堆场间的反向运输使用双向主路；堆场内部仍按大贝位到小贝位
单向行驶，需先绕行至大贝位端入口。

本次只修改地面标线及其可见性，未修改任务控制器车辆轨迹。
USD 图层解析、主场景组合、旧线隐藏已检查。俯视图为几何规划示意，
未包含所有设备实体；实际集卡转弯半径和岸桥腿部净距尚未进行车辆
扫掠验证，投入自动驾驶任务前需要验证。
