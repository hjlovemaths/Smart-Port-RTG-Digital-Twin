# RTG Control 四档雨天

RTG Control → Rain → Rain amount，保留 Light / Moderate / Heavy / Torrential 四档。
雨天开启路灯和动态作业 RTG 的下照灯，另外两台 RTG 保持关闭。
雨天每根三头路灯只保留中间一盏实际光源，灯具模型保留；夜晚恢复全部光源和原曝光。
雨天实际路灯光源限制在观察区域周围 70 米内，随雨区移动刷新，减少远处灯光的渲染开销。
使用独立阴云全景作为天空、漫射照明和反射来源，避免雨天出现蓝天和晴天硬阴影。
四档保留中性环境光；密度、湿润程度和能见度继续区分档位。

| 档位 | 累计雨滴 | 新增雨层雨线长度 | 下落速度 |
|---|---:|---:|---:|
| 小雨 | 100 | 0.18–0.38m | 5.5m/s |
| 中雨 | 350 | 0.24–0.52m | 6.5m/s |
| 大雨 | 850 | 0.32–0.70m | 8m/s |
| 暴雨 | 2000 | 0.42–0.92m | 9.5m/s |

雨线为细尾交叉面片，最多 8000 个三角形。每滴独立下落，雨线前端到达接触面后裁切，
尾端完全落下后才回收，修复整批提前回收导致的“悬空”。启用雨层合并为一个动态网格，
更新上限 60Hz，使用 NumPy 连续点缓冲上传并合并 USD 变更通知。
地面和集装箱箱顶共用一个水花网格：最多 128 个水花、2048 个三角形、30Hz 更新；
包含扩散水圈和短促弹起的小水滴，0.28 秒后完全消退，不留下静止白点。
近景还包含细雨滴的微小接触水圈，与可见雨线的落点共用同一个水花池。
使用现有距离雾，禁用可能在 RTX Real-Time 2.0 下不透明的雨天全屏遮罩。

箱顶按附近可见集装箱及 WeatheredTop 的世界包围盒顶部计算；每条受风偏移的雨滴轨迹
只命中最高的支撑面，箱内和堆叠间隙不重复生水花。箱体布局改变时最多每 0.5 秒刷新
缓存，相机移出 10 米跟随网格时重算。雨区朝视线前方偏移最多 14 米，覆盖观察中的箱顶。
这是平顶高度近似，不增加 PhysX 碰撞体或流体模拟；未实现吊机结构、斜面和竖直箱壁的遮雨。

湿润感通过已有沥青颜色与粗糙度贴图实现，不增加透明地面覆盖层或额外 clearcoat 光照层。
雨天临时改变的天空、材质、灯光均写入 session layer，退出雨天恢复进入前的 session 值。
天空贴图可用 `python omniverse/scripts/build_rain_sky.py` 重建，运行时不计算云噪声。

## 热加载

在 Kit Script Editor 执行（不保存、清空或重开场景）：

```python
import runpy
rain_preview = runpy.run_path(r"D:/dnt/project/Smart Port RTG Digital Twin/omniverse/scripts/preview_rain_effects.py")
rain_preview["reload_rain_effects"]()
```

重载器绕过 Kit 的旧模块缓存，只重载无未保存修改的天气资产，并应用当前档位。

## 帧率验证

```python
import asyncio
rain_test = asyncio.ensure_future(rain_preview["benchmark_rain_effects"]())
```

固定视角和视口尺寸，约 70 秒依次测试晴天与四档雨天，结束恢复原天气。
结果在 `tmp/rain_benchmark.json`；可在 Script Editor 用 `rain_test.result()` 查看结果或异常。
不要同时启动多个测试。

当前设备使用 4 倍帧生成，HUD 的显示 FPS 不等于原生 FPS。报告分别记录
原生渲染 FPS、含帧生成的显示 FPS、应用帧耗时与采样最低值，不更改帧生成设置。
150+ 是否满足必须以当前视角、灯光、分辨率和后台负载实测为准，不能由几何预算保证。

新版固定视角验证入口为 `omniverse/scripts/verify_rain_realism.py`，在 Kit Script Editor 用
`runpy.run_path(绝对路径, run_name="__main__")` 运行。默认每档预热 3 秒、采样 6 秒，
采样后再保存截图，校验相机姿态、分辨率以及天气退出时的材质和灯光恢复。
结果位于 `outputs/rain_realism/performance.json`；截图与采样区间分离。

## 2026-10-19 验证记录

用户将目标调整为 140+ FPS，并要求保留当前效果。固定视口 1343×585、RTX 5060、
现有 4 倍帧生成下，中雨显示 FPS 中位数 146.0、采样最低 144.6；小雨中位数 148.0。
大雨和暴雨仍有低于 140 的采样，贴近箱顶等其他视角也不能保证 140+。
这些数字是固定视角的显示帧率，不是原生渲染帧率或所有视角的最低保证。
