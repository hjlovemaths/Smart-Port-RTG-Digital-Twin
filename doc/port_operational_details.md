# 港区作业环境细节

2026-10-26：沿 1C–4C 两侧绿化带及四座连接桥增加一轮静态环境细节。

- 8 块双面分区牌：标注真实分区及贝位范围，1C–3C 为 001–091，4C 为 001–041。
- 8 处消防设施示意点：消防柜、消火栓和黄黑防撞柱。
- 72 处排水格栅、114 簇低矮灌木。
- 80 块桥栏黄白安全标识，不使用自发光模拟反光。

模型合并为 35 个网格、29,272 个三角面，复用不透明材质。增加 8 盏低功率无阴影标牌照明，接入现有昼夜控制；无新纹理、物理碰撞、逐帧回调。消防和排水设施均为视觉模型。

新增设施限定在原有绿化带 X=-101.75..-85.875 和 X=105.25..110.5，保留每条横向道路开口；桥栏标识位于距桥中心约 4.2 米处，避开行车净空。未修改集装箱库存、设备控制坐标及交通网络。

- 模型：`omniverse/scenes/port_operational_details.usda`，主场景已引用。
- 生成：`omniverse/scripts/build_port_operational_details.py`。
- 检查：`omniverse/scripts/verify_port_operational_details.py`，验证网格、材质、依赖、道路和 RTG 走行范围净空。
- Kit 预览：`omniverse/scripts/preview_port_operational_details.py`；比较同一视角新增前后效果与帧率，结束后恢复原视角和时间，不保存其他场景编辑。
- 输出：`outputs/port_operational_details/`。

帧率报告分别列出原生 FPS 和根据当前帧生成倍率估算的显示 FPS；固定视角结果不能保证全场景最低帧率。
