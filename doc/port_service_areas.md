# 远控中心与 4C 末端配套模型

参考用户提供的港口模型布局，按现有场景坐标增加轻量化静态配套设施。

## 布置

- 远控中心：13 个停车位、6 辆示意车辆、门卫亭、入口雨棚、人行铺装、座椅、沿岸护栏和绿化。
- 4C 40/41 贝后方：2 间检修库、1 间备件库、1 间设备间、配电柜、2 排遮阳停车棚及休息绿地。
- 建筑采用灰白墙体、蓝灰金属屋面、深色窗、卷帘门、屋顶设备和防撞柱；细节以几何模型实现。

## 坐标与道路约束

远控中心原建筑位于 X=133.4..142.6、Y=462..478；新配套位于外围主路东侧 X>125.5。
4C 原堆场末端约为 Y=446.25。新配套限定 Y>454、Y<492.6，保留末端约 8 米缓冲带和 Y=496.3 的横向道路。
每个服务地块位于原堆场列中心 X 的右侧 +0.35..+7.375 米，保留既有作业车道及相邻列间道路。不修改箱位、RTG、岸桥、船舶或交通控制坐标。

## 文件与维护

- `omniverse/scenes/port_service_areas.usda`：独立配套模型图层，主场景已引用。
- `omniverse/scripts/build_port_service_areas.py`：可重复生成模型；用包含 pxr 的 Kit Python 运行。
- `omniverse/scripts/verify_port_service_areas.py`：检查材质、网格索引、资源依赖、所有顶点与道路的净空以及几何预算。
- `omniverse/scripts/preview_port_service_areas.py`：在 Kit 脚本编辑器通过 runpy 运行，输出相同视角的前后对比、帧率数据，并恢复原相机。不保存当前主场景中的其他未保存修改。
- `outputs/port_service_areas/`：预览图、生成统计、实测数据。

新增 31 个按区域和材质合并的网格，共 14,970 个三角面；无新纹理、动态灯光、碰撞体或逐帧脚本。车辆和建筑是静态环境模型。

帧率记录同时提供原生渲染值和现有帧生成倍率下的估算显示值；不可将含帧生成的显示帧率描述成原生帧率。预览程序每个状态预热 8 秒、采样 5 秒，具体数字见 validation_live.json。
